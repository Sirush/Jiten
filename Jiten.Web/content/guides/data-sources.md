The dictionary data comes from:

- [JMdict](https://www.edrdg.org/wiki/index.php/JMdict-EDICT_Dictionary_Project), [JMnedict](https://www.edrdg.org/wiki/index.php/JMnedict) and [KANJIDIC](https://www.edrdg.org/wiki/KANJIDIC_Project.html), property of the [Electronic Dictionary Research and Development Group](https://www.edrdg.org/) and used under its [licence](https://www.edrdg.org/edrdg/licence.html).
- Kanji stroke order and components from [KanjiVG](https://kanjivg.tagaini.net) by Ulrich Apel, licensed under [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).

For the metadata, these APIs are used:

- Some metadata (descriptions, tags, and ratings) is derived from [VNDB](https://vndb.org), licensed under the [Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
- [TMDB](https://www.themoviedb.org)
  ![TMDB logo](/img/guides/tmdb.svg){.guide-logo}
  [This product uses the TMDB API but is not endorsed or certified by TMDB.]{.guide-attribution}
- [AniList](https://anilist.co)
- [IGDB](https://igdb.com)
- [Google Books](https://www.google.com/books)

The sources for the data are:

- Subtitles from [Jimaku](https://www.jimaku.cc)
- Game scripts from [Jo-Mako](https://sites.google.com/view/jo-mako/resources/resources-list?authuser=0)
- Some VN scripts from [Wareya](http://wiki.wareya.moe/Stats)
- Everything else comes from me or our generous contributors on [Discord](https://discord.gg/cZWM7b4wzk)!

Audio pronunciations are generated using [VOICEVOX](https://voicevox.hiroshiba.jp/) with voices [四国めたん](https://zunko.jp/con_ongen_kiyaku.html) (Female 1), [九州そら](https://zunko.jp/con_ongen_kiyaku.html) (Female 2, ASMR), [剣崎雌雄](https://frontier.creatia.cc/fanclubs/413/posts/4507) (Male 1), and [青山龍星](https://virvoxproject.wixsite.com/official/voicevox) (Male 2).
