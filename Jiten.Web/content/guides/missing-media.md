While I aim to make the website as complete as possible, it's an arduous process and I have to prioritise some media over others. If you'd like something added, you can submit a request on the [requests page](/requests) after creating an account. Requests are fulfilled depending on availability to source the text.

## New media or an update?

When you file a request, you can tick **"This is an update to an existing media"** and pick the media it concerns. Use it when the page already exists but something about it is wrong or incomplete:

- volumes, episodes or chapters are missing
- the text is from the wrong edition or release
- the script is inaccurate, or the example sentences are badly formatted

Leave the box unticked for media that has no page at all.

If someone has already filed an update request for the same media, it will show up when you fill the form. Voting on that one helps more than filing a second.
