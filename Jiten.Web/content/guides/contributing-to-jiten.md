Almost everything in the library is here because someone asked for it, shared the scripts, or reported an issue. You can do the actions below with an account.

## Voting for what gets added next

Media requests are available on the [requests page](/requests), which you reach from your profile button in the header.

The most voted requests have a higher chance to be picked first, depending on the availability of the media. You can click the chevron button on any request to vote it up, giving it more visibility. Voting for a title already on the list is worth more than filing a second copy of it, so search before you add a new request.

Voting also subscribes you to the request, so you will be immediately notified when the request is fulfilled.

With [Jiten+](/jiten-plus) you also get five **Boosts** a month. A boost permanently adds the weight of five votes to one request.

## Filing a request

Press **New Request**.

1. Leave **This is an update to an existing media** unticked for a title with no page at all. Tick it when the page exists but is missing volumes, uses the wrong edition, or has a bad script, then pick the title under **Media to update**.
2. Choose a **Media Type** and enter the **Title**.
3. Paste a database link into **External URL**. Anilist, VNDB, TMDB, MyAnimeList, IGDB, Bookmeter and similar sites are all fine, piracy sites are not. A request without a link takes longer and the wrong version might be added.
4. Use **Description** for any notes you want to leave, such as the romanisation of the name.

Existing media, and any similar request that is open or already in progress, appear under the title field as you type, which can help you avoid duplicates.

You have **20** active request slots, or **30** with [Jiten+](/jiten-plus). You get your slot back once a request is fulfilled or rejected.

## Reporting what looks wrong

Media have a **Report an issue** button when you are logged in, that you can use to report any issue with a title.

Pick the relevant option, then fill in the details. Issues will be fixed in a timely manner, but you won't get any notification.

## Rating difficulty

Once you have marked a few titles **Completed**, the **Ratings** link in the header lets you compare them against each other, which improves the difficulty scores for everyone. See [Difficulty ratings](/guides/difficulty-ratings).

## Everything else

The [Discord](https://discord.gg/cZWM7b4wzk) is where bug reports, feature ideas and everything else happen. Both projects are open source and take issues and pull requests: [Jiten](https://github.com/Sirush/Jiten) and [Jiten Reader](https://github.com/Sirush/JitenReader). You can also help financially by subscribing to [Jiten+](/jiten-plus) or [donating](/donate) with GitHub Sponsors, Ko-fi and Patreon.

Open the [requests page](/requests) and vote for the titles you would most like to see added.
